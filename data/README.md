# Data

This directory contains all data-related resources used in the project.

The repository does **not** include raw or processed datasets due to size and licensing constraints.

## Structure

```
data/
├── raw/         # Raw datasets (not versioned)
├── processed/   # Generated datasets (not versioned)
└── sample/      # Small versioned examples for testing
```

---

## `raw/`

This folder is intended to store the original datasets.

For this project, it should contain the Yelp Open Dataset files:

- `yelp_academic_dataset_business.json`
- `yelp_academic_dataset_review.json`
- `yelp_academic_dataset_user.json`

### How to populate

1. Download the Yelp dataset from the official source.
2. Extract the files.
3. Place them in `data/raw/`.


---

## `processed/`

This folder contains datasets generated by preprocessing and pipeline scripts.

### Typical generated files

| File pattern | Description | Produced by |
|---|---|---|
| `yelp_subset*.jsonl` | Processed Yelp subset with user history and target item | `scripts.build_yelp_subset` |

| `*_with_review_aspects_nli.jsonl` | Dataset enriched with extracted review aspects | `scripts.extract_review_aspects_nli` |

| `aspect_mf_dataset*.csv` | User-aspect-rating dataset for aspect-based MF | `scripts.build_aspect_mf_dataset` |

| `aspect_mf_predictions*.json` | Aspect-MF predictions used in argument scoring | `scripts.train_aspect_mf` |

| `generated_arguments_*.jsonl` | LLM-generated recommendation arguments | `scripts.generate_batch` |

| `*_valid.jsonl` / `*_invalid.jsonl` | Valid / invalid generated outputs after validation | `scripts.generate_batch` |

| `scored_arguments_*.jsonl` | Arguments enriched with LLM, MF and combined scores | `scripts.score_batch` |

| `dfquad_*.jsonl` | Final argumentative aggregation outputs | `scripts.dfquad_batch` |

| `mf_dataset*.csv` | User-item-rating dataset for MF-only baseline | `scripts.build_mf_dataset` |

| `mf_item_predictions*.json` | MF-only target-item predictions | `scripts.train_mf` |

| `llm_direct_scores_*.jsonl` | LLM-only direct score predictions | `scripts.llm_direct_score` |

| `yelp_ranking_candidates_*.jsonl` | Ranking candidates with 1 positive item and N negatives | `scripts.build_ranking_candidates` |

| `evaluation_*.csv` | Per-example evaluation results | Evaluation scripts |

| `evaluation_*_summary.json` | Aggregated evaluation metrics (MAE, RMSE, HitRate@K, NDCG@K, MRR) | Evaluation scripts (`scripts.evaluate_dfquad_scores`, `scripts.evaluate_ranking`) |


Example:

```bash
python -m scripts.build_yelp_subset
```

This folder can be regenerated at any time with the Yelp dataset.

---

## `sample/`

This folder contains small **versioned** example datasets.

It is meant to document the expected input format, support quick testing without downloading Yelp, and help with debugging and reproducibility.

Example: `sample_input.jsonl`

These files are intentionally small and are synthetic or manually constructed examples. No original Yelp data is redistributed in this repository.
